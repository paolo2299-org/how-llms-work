Full LLM

A full language model turns a prompt into a probability distribution for the next token. Everything on this page is the same idea used by large models, but with a tiny five-token sequence and six-dimensional vectors so the shapes stay visible.

We will connect the earlier pieces together: tokenisation, token embeddings, positional information, a stack of transformer blocks, a final normalisation, and an output head that scores every token in the vocabulary.

The whole model at a glance

Step 1 — turn text into token IDs

Suppose the prompt is “the dog fetched the ball”. The tokenizer maps each piece of text to an integer ID from a fixed vocabulary. The model never receives raw characters; it receives these IDs.

Step 2 — look up token and position embeddings

Each token ID selects one row from a learned embedding table. A second learned table supplies position vectors, because the same word in position 0 and position 3 should not look identical to the model. The two vectors are added together.

x = token_embedding[token_ids] + position_embedding[positions]
# x has shape (sequence_length, embed_dim) = (5, 6)

Step 3 — run the transformer stack

The sequence tensor flows through many identical transformer blocks. Each block keeps the same shape, which is what makes stacking possible. Earlier blocks tend to build local and syntactic features; later blocks can combine those into more task-specific representations.

for block in self.blocks:
    x = block(x)  # still (5, 6)

The causal mask is crucial during generation. The representation at each position may use that token and earlier tokens, but not later tokens. That is why the final position is the one used to predict the next token.

Step 4 — convert the last position into vocabulary scores

After the final block, the output head projects each position from the embedding width to the vocabulary size. If the vocabulary has 50,000 tokens, every position gets 50,000 raw scores called logits.

logits = output_head(final_norm(x))
next_token_logits = logits[-1]  # use the final prompt position
example final-position logits

logit3.82.11.4-0.60.9

Step 5 — softmax turns scores into probabilities

Softmax converts logits into probabilities. Larger logits become more likely, but lower-scoring tokens can still have non-zero probability. A decoding rule then chooses the next token: greedy decoding takes the highest probability, while sampling introduces controlled randomness.

probabilities = softmax(next_token_logits)
next_token = sample(probabilities)  # for example: "on"

Full implementation

Putting the pieces together gives the shape of a small decoder-only language model:

import torch
import torch.nn as nn


class TinyLanguageModel(nn.Module):

    def __init__(self, vocab_size, max_seq_len, embed_dim, num_heads, hidden_dim, num_layers):
        super().__init__()
        self.token_embedding = nn.Embedding(vocab_size, embed_dim)
        self.position_embedding = nn.Embedding(max_seq_len, embed_dim)
        self.blocks = nn.ModuleList([
            TransformerBlock(embed_dim, num_heads, hidden_dim)
            for _ in range(num_layers)
        ])
        self.final_norm = nn.LayerNorm(embed_dim)
        self.output_head = nn.Linear(embed_dim, vocab_size)

    def forward(self, token_ids):
        positions = torch.arange(token_ids.size(0), device=token_ids.device)
        x = self.token_embedding(token_ids) + self.position_embedding(positions)
        for block in self.blocks:
            x = block(x)
        x = self.final_norm(x)
        logits = self.output_head(x)
        return logits

Training

During training, the model sees many text sequences and learns to make the next-token logits assign high probability to the real next token.

Generation

During generation, the model predicts one next token, appends it to the prompt, and repeats the same forward pass.
