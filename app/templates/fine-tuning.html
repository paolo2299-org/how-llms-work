Instruction fine-tuning

At the end of pre-training, a language model is good at continuing text. It has learned from a huge variety of writing, but it has not necessarily learned that a user’s request should be followed or that an answer should be clear and useful.

Instruction fine-tuning gives the pre-trained model further training on examples of instructions paired with good responses. The aim is to turn the model’s broad ability to predict text into more reliable behaviour: interpret the request, follow its constraints, and respond in an appropriate form.

Fine-tuning starts with the weights learned during pre-training. It adjusts those weights; it does not build a new model from scratch.

Build a dataset of demonstrations

The training data contains many demonstrations of the behaviour we want. Some can be written by people, some can be adapted from existing data, and some can be produced by another model and then checked or filtered.

Answer a question

User
Why does the Moon appear to change shape?
Good response
The Moon does not change shape. As it orbits Earth, we see different amounts of its sunlit half, creating the phases of the Moon.

Transform some text

User
Rewrite this politely: “Send me the figures today.”
Good response
Could you please send me the figures today?

Follow a format

User
Give me three names for a bakery. Use a bulleted list.
Good response
  • Golden Crumb
  • Morning Loaf
  • Flour & Hearth

A useful dataset varies the wording, subject, difficulty, and desired response style. It may also contain multi-turn conversations, where each response needs to take account of earlier messages. Across many examples, the model can learn that the instruction itself—not a particular stock phrase—determines what kind of answer should follow.

Train on the desired responses

The learning mechanism is closely related to pre-training. The model reads the instruction and the response so far, predicts the next token of the good response, and is penalised when it gives the correct token a low probability. Backpropagation then makes small adjustments to the model’s weights.

  1. DemonstrationChoose an instruction and its good response
  2. PredictionAsk the model to predict each response token
  3. LossMeasure how far its predictions are from the response
  4. UpdateAdjust the weights, then repeat across the dataset

Usually, the instruction is supplied as context but the training loss is focused on the response. We want the model to learn what to say after an instruction, rather than to learn to reproduce the user’s words.

A worked training example

Suppose one demonstration asks the model to rewrite a sentence politely:

Instruction
Rewrite this politely: “Send me the figures today.”

Desired response
Could you please send me the figures today?

The response is broken into tokens. During training, the model is repeatedly shown the instruction and the correct response up to a particular point:

A simplified view of three next-token predictions
What the model has seen Token it should predict What is learned
The instruction Could A polite rewrite can begin with a courteous request
The instruction + “Could” you The response should continue as a natural sentence
The instruction + “Could you please send me the figures” today The important content of the original should be preserved

The weight update is based on all of these predictions together. One example makes only a tiny difference. Repeating the process across many varied demonstrations gradually makes responses that follow instructions more likely.

What the model learns

The demonstrations do not provide an explicit rulebook. Instead, they shape the probabilities of possible responses. For example, training across the demonstrations above can make the model more likely to:

  • answer the question instead of merely continuing or restating it
  • preserve relevant details while transforming text
  • follow constraints such as tone, length, or output format
  • use the roles in a conversation to distinguish user requests from assistant replies
Instruction fine-tuning does not guarantee a correct answer. The model can still misunderstand a request, invent information, or fail on unfamiliar tasks. It teaches a pattern of responding; other post-training stages can further optimise helpfulness, safety, and reliability using human or model feedback.
