Token Embeddings

Each word is represented as a point in a high-dimensional space — its position encodes meaning. Words with similar meanings end up nearby. Below we show a 3D projection of 50-dimensional GloVe vectors, so some distance relationships are approximate.

Try: cat, dog, fish — or king, queen, prince

These are static word embeddings (GloVe). Modern LLMs use contextual embeddings — the same word gets a different vector depending on surrounding words — but the core idea of meaning as position in space is the same.

Self-Attention

Transformers use self-attention to let each token look at other tokens in the same sequence and decide which ones are most relevant. Each token acts as a query, searching through the other tokens for useful information. Different attention heads can specialise in different kinds of relationships — some track grammar, some track meaning, some track position.

Click a word to select it as the query token. The amber highlight shows which tokens it attends to. Darker means stronger attention.
